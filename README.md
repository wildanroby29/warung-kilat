Warung Kilat is a neon-lantern night-market cooking game: take orders from the ticket rail, cook ingredients at four stations (steamer, grill, wok, chopping board), assemble dishes layer by layer on the plate, and serve before a customer's patience runs out. Five nights, five Indonesian dishes, rush hours and VIP customers. All art is drawn in code on canvas and all sound is synthesized with WebAudio — no network, no dependencies, no image files.

## Run it

```sh
python3 -m http.server 8000 --directory game
```

Then open http://localhost:8000 in a desktop browser. Or simply open `game/index.html` directly — the game also works from `file://`.
